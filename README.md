
## 🚀 DevOps e CI/CD

O RotuScan utiliza práticas de DevOps para automatizar verificações de qualidade, implantação e monitoramento da aplicação.

- **Integração contínua:** GitHub Actions
- **Testes automatizados:** Node.js Test Runner
- **Qualidade de código:** ESLint
- **Deploy contínuo:** Render
- **Banco de dados:** MongoDB Atlas
- **Monitoramento:** Render e UptimeRobot
- **Health Check:** [Status da API](https://rotuscan-api.onrender.com/api/health)
