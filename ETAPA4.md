# RotuScan — Etapa 4: restauração visual

Recriação das telas de Pacientes, Dashboard, Receitas (com filtros e modal) e Configurações a partir das capturas fornecidas, preservando frontend modular e backend MongoDB.

## Observações
- O projeto **não inclui credenciais**. Reutilize seu `.env` do backend anterior.
- Pacientes e receitas são **demonstrativos**, sem conexão com dados reais de pacientes.
- Dashboard mantém indicadores vazios por segurança, até vinculação autorizada.
- Ingredientes e preparos das receitas são ilustrativos e não devem ser usados como orientação nutricional.
- A compilação não pôde ser validada neste ambiente porque a instalação das dependências não foi concluída. Execute `npm.cmd install` e `npm.cmd run build` no seu computador.

## Executar
Na raiz do frontend: `npm.cmd install` e `npm.cmd run dev`. No backend: `npm.cmd install` e `npm.cmd run dev`.
